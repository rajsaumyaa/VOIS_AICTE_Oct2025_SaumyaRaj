# 🏠 Airbnb Price Prediction — VOIS AICTE Project (Oct 2025)

## 📘 Project Overview  
This project focuses on developing a **machine learning model** to predict Airbnb listing prices using historical data.  
Pricing plays a crucial role for both hosts and travelers — hosts aim to maximize occupancy and revenue, while travelers look for fair and competitive rates.  

The model identifies how different features such as **location, bedrooms, bathrooms, property type, and guest ratings** influence pricing. It can also predict prices for new or hypothetical listings, helping property owners make **data-driven pricing decisions**.

---

## 🎯 Project Objectives  
- Analyze the relationship between listing attributes and price  
- Build and evaluate regression models for price prediction  
- Provide insights into the key factors influencing Airbnb prices  
- Help hosts optimize pricing to improve revenue and occupancy  
- Predict prices for unseen or hypothetical properties

## ⚙️ Requirements & Setup  

### Prerequisites  
- Python 3.7 or higher  
- Jupyter Notebook / Google Colab  
- Libraries:  
pandas
numpy
matplotlib
seaborn
scikit-learn

---

### Installation  

1. Clone this repository:  
 ```bash
 git clone https://github.com/rajsaumyaa/VOIS_AICTE_Oct2025_SaumyaRaj.git
 cd VOIS_AICTE_Oct2025_SaumyaRaj
```

2. (Optional) Create a virtual environment:

```
python -m venv venv
source venv/bin/activate    # On Windows: venv\Scripts\activate
```
3. Install dependencies:

```
pip install -r requirements.txt


If requirements.txt is not available, install packages manually using:

pip install pandas numpy matplotlib seaborn scikit-learn

```

🚀 How to Run

```
Open the Jupyter Notebook:

jupyter notebook AirBNB_Source_Code.ipynb

```
or upload it to Google Colab.

Run the cells step by step to:

1. Load and preprocess the dataset

2. Perform exploratory data analysis (EDA)

3. Train regression models (e.g., Linear Regression, Random Forest, XGBoost)

4. Evaluate model performance using metrics like RMSE, MAE, and R²

5. Generate predictions for test or new listings
